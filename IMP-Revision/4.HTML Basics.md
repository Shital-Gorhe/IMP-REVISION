#### **🎯 What is HTML?**



**HTML** = HyperText Markup Language

It is the skeleton of a webpage

Tells browser what to show — not how it looks



**📋 Basic Structure**

html

<!DOCTYPE html>

<html>

&#x20; <head>

&#x20;   <title>My Page</title>

&#x20; </head>

&#x20; <body>

&#x20;   <h1>Hello World!</h1>

&#x20; </body>

</html>









###### **Tag			Purpose**

<!DOCTYPE html> 	Tells browser it's HTML5

<html>			Root of the page

<head>			Meta info — title, CSS links

<title>			Tab name in browser

<body>			Visible content

**🔑 Important Attributes**



###### **Attribute	   Use			   Example**

id			Unique identifier		id="header"

class			Group elements			class="btn"

href			Link URL	        	href="page.html"

src			Image/script source		src="img.jpg"

alt			Image description		alt="logo"

style			Inline CSS			style="color:red"

target			Link open behaviour		target="\_blank"

placeholder		Input hint text			placeholder="Name"





🆚 Most Asked Comparisons

###### **div vs span**

<div>	         	<span>

Block element		Inline element

Takes full width	Takes only content width

Used for sections	Used for small text parts





##### **id vs class**

id					class

Unique — one element only	Can be reused on many elements

\#header in CSS	     		.btn in CSS

<p id="name">Gauri</p>  	<p class="title">Hello</p>

&#x09;			.title {color: blue;}





###### **<b> vs <strong>**

<b>				<strong>

Just bold visually	Bold + semantic meaning





##### **📝 Semantic Tags (HTML5)**

<header>   → top section

<nav>      → navigation links

<main>     → main content

<section>  → group of content

<article>  → independent content

<footer>   → bottom section

<aside>    → sidebar content



Used instead of <div> — gives meaning to the structure
