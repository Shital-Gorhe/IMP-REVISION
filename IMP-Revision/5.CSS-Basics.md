##### **1. What is CSS?**

**CSS** = Cascading Style Sheets

Used to style HTML elements.





###### **6. Margin vs Padding ⭐**



&#x20;     margin

&#x20;  ┌─────────────┐

&#x20;  │   border     │

&#x20;  │ ┌─────────┐ │

&#x20;  │ │ padding │ │

&#x20;  │ │ content │ │

&#x20;  │ └─────────┘ │

&#x20;  └─────────────┘



\- Margin → space outside the element

\- Padding → space inside the element



Memory:

Margin = outside

Padding = inside





##### **Types**



**1. Inline CSS**

CSS written inside the HTML element.



<p style="color: red;">Hello</p>



**➡️ Used for one specific element.**







**2. Internal CSS**

CSS written inside <style> in the same HTML file.



<style>

&#x20;   p {

&#x20;       color: blue;

&#x20;   }

</style>



**➡️ Used for one webpage.**









**3. External CSS ⭐**

CSS written in a separate .css file.



HTML:

<link rel="stylesheet" href="style.css">



style.css:

p {

&#x20;   color: green;

}



**➡️ Used to reuse CSS across multiple webpages.**





Memory trick

Inline → one element

Internal → one page

External → multiple pages
