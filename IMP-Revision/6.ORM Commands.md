#### ORM -- 

🎯 What is ORM?



ORM = Object Relational Mapper

Write Python code instead of SQL queries

Django converts it to SQL automatically!





Python

\# SQL way

SELECT \* FROM students;



\# ORM way

Student.objects.all()

#### **✅ Must Know Queries**

###### **Get All Records**

Student.objects.all()



###### **Get One Record**

Student.objects.get(id=1)       # exact match — error if not found



###### **Filter Records**

Student.objects.filter(city="Pune")          # WHERE city = 'Pune'

Student.objects.filter(marks\_\_gte=60)        # WHERE marks >= 60

Student.objects.filter(city="Pune", age=20)  # multiple conditions



###### **Exclude Records**

Student.objects.exclude(city="Mumbai")       # WHERE city != 'Mumbai'



###### **Count Records**

Student.objects.count()                      # total records

Student.objects.filter(city="Pune").count()



###### **Order Records**

Student.objects.order\_by("marks")            # ascending

Student.objects.order\_by("-marks")           # descending (- means DESC)



###### **First and Last**

Student.objects.first()

Student.objects.last()



###### **Create Record**

Student.objects.create(name="Rahul", age=20, city="Pune", marks=85)



###### **Update Record**

Student.objects.filter(id=1).update(marks=90)



###### **Delete Record**

Student.objects.filter(id=1).delete()



###### **Check Exists**

Student.objects.filter(city="Pune").exists()   # True / False





###### **🔍 filter() vs get()**

&#x09;	filter()	      	   get()

Returns	        QuerySet (list)		Single object

No match	Empty QuerySet		❌ DoesNotExist error

Multiple	All matching		❌ MultipleObjectsReturned

Use when	Expecting many		Expecting exactly one







###### **🧠 Lookup Shortcuts**

python

\_\_gte   →  >=          marks\_\_gte=60

\_\_lte   →  <=          marks\_\_lte=40

\_\_gt    →  >           age\_\_gt=18

\_\_lt    →  <           age\_\_lt=25

\_\_contains → LIKE      name\_\_contains="Ra"

\_\_startswith           name\_\_startswith="R"

\_\_in    → IN list      city\_\_in=\["Pune","Mumbai"]





###### **🎯 One Line Summary**

all()      → get everything

get()      → get one exact record

filter()   → get all matching records

exclude()  → skip matching records

create()   → add new record

update()   → change existing record

delete()   → remove record

exists()   → True / False check
