Top 30 Questions (Must Prepare)



**What is an if statement?**

An if statement is a **decision-making statement** that executes a block of code only if the given condition is True.

If the condition is False, the block is skipped.



**if vs if-else.**

if executes code only when the condition is true, whereas if-else provides two alternatives: one block runs if the condition is true, and the other runs if it is false.



**if-elif-else.**

The if-elif-else statement is used when there are **multiple conditions** to check.



**Nested if.**

A nested if means placing one if statement inside another if statement.

It is used when **one condition should be checked only after another condition is true.**



**for loop.**

A for loop is used to iterate over a sequence such as a string, list, tuple, set, dictionary, or range.



**while loop.**

A while loop executes a block of code as long as the given condition is True.



**for vs while.**

| `\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\*\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\*for` Loop\*\*                                   | `\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\*\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\*while` Loop\*\*                                                |

| -------------------------------------------- | ----------------------------------------------------------- |

| Used when the number of **iterations is known.** | Used when the number of **iterations is unknown**.              |

| Iterates over a sequence.                    | Runs until a given condition satisfy                      |

| Simpler for traversing collections.          | Better when repetition depends on a condition.              |

| **Less** chance of **infinite loops**.               | Can become an **infinite loop** if the condition never changes. |



**range().**

range() is a built-in function that generates a sequence of integers. It is commonly used in for loops for controlling the number of iterations.



**break()**

The break statement immediately exits the current loop when a specified condition is met.



**continue.**

The continue statement skips the current iteration and moves to the next iteration of the loop.



**pass.**

The pass statement is a placeholder.

It does nothing but allows the program to run without errors



**Nested loops.**

A nested loop is a loop inside another loop.

The inner loop executes completely for every iteration of the outer loop.

## MODULE AND PACKAGES

**What is a module?**

A module is a Python file (.py) that contains functions, classes, variables, or executable code.

Instead of writing all the code in one file, we divide it into multiple modules to make the program organized and reusable.

A module allows us to reuse code by importing it into other Python programs.

**Why do we use modules?**

Modules improve code reusability, organization, readability, maintenance, and reduce code duplication.

**What are the types of modules?**

Built-in modules provided by Python.

User-defined modules created by programmers.



**How do you import a module?**

1.Import the entire module-import math

2\. Import with an alias-import math as m

3\. Import specific functions-from math import sqrt

4\. Import multiple functions-from math import sqrt, factorial

5\. Import everything-from math import \*



**What is an Alias?**

An alias is an alternate name given to a module during import using the as keyword.



**What happens if Python cannot find a module?**

ModuleNotFoundError



**What is a package?**

A package is a directory that contains one or more related Python modules. It helps **organize large projects**, improves code reusability, and provides a **hierarchical structure** for managing modules.

**Module vs Package.**

An exception is an **event** that occurs during the **execution** of a program and **interrupts** the normal flow of the program.

**Exception vs Error.**

\*\*Error-\*\*An error is a broader term. It usually refers to problems that prevent the program from running correctly. Some errors (such as syntax errors) must be fixed in the code before the program can run.

**What is encapsulation?**

**Real-life examples of encapsulation.**

Think of an ATM Machine.

You can:

Insert your ATM card

Enter your PIN

Withdraw money

Check balance

But you cannot directly access the bank's internal database or change your account balance manually.

The ATM hides the internal implementation and provides only the required operations.

This is encapsulation.



**Advantages of encapsulation.**

data security,

data hiding,

better code organization,

easier maintenance,

improved reusability,

controlled access to data.



**Data hiding.**

Data hiding means **restricting direct access to the data** and allowing access only **through controlled methods**.
