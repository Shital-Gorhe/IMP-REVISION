###### **1. Git solves:** "How do I manage changes in my code?"

Imagine you are working on a Python project:

Monday → code is working

Tuesday → you change something → code breaks

Wednesday → you want Monday's working code back

Without Git, you might create:

project\_final.py

project\_final2.py

project\_final\_latest.py

project\_final\_latest\_REAL.py

😅

Git solves this problem by keeping a history of your changes.

You can:

\- See what changed

\- Go back to an older version

\- Create separate branches for new features

\- Work safely without losing previous versions





**2. GitHub solves**: "How do I store and share my Git project online?"

Git mainly works on your computer.

GitHub gives you an online copy of your repository.

GitHub allows you to:

\- Store your project online

\- Share it with others

\- Collaborate with teammates

\- Review code through Pull Requests

\- Keep a remote backup of your project
